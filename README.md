Subscription Waste Detector

About the Project

Subscription Waste Detector is a Java-based desktop application that helps users manage their paid subscriptions, track monthly and yearly expenses, and identify subscriptions that are not used regularly.

The application provides a simple graphical user interface (GUI) to make subscription management easier.

Technologies Used

- Java
- Java Swing (GUI)
- MySQL
- JDBC (Java Database Connectivity)
- IntelliJ IDEA

Features

- Add Subscription: Add new subscription details.
- View Subscriptions: Display all saved subscriptions in a table.
- Monthly Spending: Calculate total monthly subscription expenses.
- Unused Subscriptions: Identify subscriptions that have not been used for 30 days or more.
- Search Subscription: Search for subscriptions by name.
- Update Subscription: Modify existing subscription details.
- Delete Subscription: Remove subscriptions from the database.
- Potential Savings: Estimate possible monthly savings from unused subscriptions.

Database

The project uses MySQL to store subscription details. JDBC is used to establish a connection between the Java application and the MySQL database.

How It Works

Users can manage their subscriptions through a Java Swing dashboard. Subscription details are stored in MySQL, and the application retrieves the data to calculate expenses and identify potentially unused subscriptions.
